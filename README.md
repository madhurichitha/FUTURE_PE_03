# AI SEO Blog & Content Cluster Generator

## Future Interns – Prompt Engineering Internship | Task 3

### Project Overview

This project demonstrates an AI-assisted SEO content generation system designed for a real business website.

The objective is to use structured prompt engineering to create a complete SEO content cluster consisting of one pillar blog and multiple supporting blogs.

### Business Selected

**Business:** Salon Nayana  
**Location:** Bengaluru, Karnataka, India  
**Business Type:** Hair & Beauty Salon

### Primary SEO Topic

**Hair Extensions in Bangalore**

### Primary Keyword

**hair extensions in Bangalore**

### Search Intent

The primary keyword has **commercial investigation intent**. Users searching for this topic are likely researching hair extension options, pricing, suitability, maintenance and salons before making a decision.

## SEO Content Cluster

### Pillar Blog

**Hair Extensions in Bangalore: Types, Cost, Maintenance & How to Choose the Right One**

The pillar article provides a comprehensive overview of hair extensions and acts as the central page of the content cluster.

### Supporting Blogs

1. **How Much Do Hair Extensions Cost in Bangalore?**
2. **Types of Hair Extensions: Which One Is Right for You?**
3. **How to Maintain Hair Extensions: A Complete Care Guide**
4. **Hair Extensions vs Hair Wigs: Which Should You Choose?**
5. **What to Know Before Getting Hair Extensions in Bangalore**

## Keyword Strategy

The keyword strategy combines:

- Primary location-based keyword
- Supporting long-tail keywords
- Informational search queries
- Commercial investigation queries
- Question-based keywords
- Related semantic terms

The content cluster is designed to target different stages of the user's search journey while maintaining topical relevance.
