# Master SEO Content Cluster Prompt

## Purpose

Generate a complete SEO content strategy and content cluster for a local business website using structured prompt engineering.

## Master Prompt

Act as an experienced SEO content strategist and prompt engineer.

Create a helpful, search-intent-focused SEO content cluster for the following business:

**Business:** Salon Nayana  
**Location:** Bengaluru, Karnataka, India  
**Business Type:** Hair & Beauty Salon  
**Main Service Topic:** Hair Extensions

### Primary Keyword

hair extensions in Bangalore

### Main Objective

Create an SEO content system that can increase organic visibility, build topical authority, educate potential customers and support service enquiries.

### Required Output

Generate the following:

1. Primary keyword and search intent
2. Related keywords and long-tail keywords
3. One pillar blog topic
4. 3–5 supporting blog topics
5. H1–H3 structure for the pillar blog
6. Long-form pillar blog content
7. Long-form supporting blog content
8. Internal linking recommendations
9. Local SEO opportunities
10. SEO title and meta description for each article
11. Relevant calls to action

### Content Requirements

- Write for real users first and search engines second.
- Use natural keyword placement.
- Avoid keyword stuffing.
- Provide clear and useful information.
- Use logical H1, H2 and H3 headings.
- Keep paragraphs readable.
- Include relevant examples where appropriate.
- Match each article to its search intent.
- Connect supporting articles to the pillar article through internal links.
- Use Bengaluru/Bangalore naturally for local SEO.
- Maintain a professional but approachable tone.
- Focus on helpful, trustworthy content.

### Accuracy Guidelines

Do not:

- Invent customer reviews or testimonials.
- Invent prices, discounts or offers.
- Make unsupported medical or clinical claims.
- Guarantee Google rankings.
- Present unverified business information as fact.
- Create fake statistics.
- Claim that AI-generated information has been verified.

If a business-specific fact cannot be verified, clearly identify it as information that requires confirmation before publication.

### Reusability

Keep the prompt structure reusable.

The business name, location, service, primary keyword and target audience should be replaceable so the same prompt can be adapted for other local businesses.

## Expected Outcome

The final output should resemble an SEO agency content strategy that includes:

**1 Pillar Blog + 3–5 Supporting Blogs + Keyword Strategy + Search Intent + Internal Linking + Local SEO + Business-focused CTAs**
